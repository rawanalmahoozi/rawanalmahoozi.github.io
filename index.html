Client-server application

News API Client-Server Application

Outcome

A working news application that serves multiple clients at once, displays news in a readable format and keeps a record of client requests.

Users needed an easy way to request and browse news through a client-server architecture that supports multiple connections. I built a Python application using TCP sockets, multithreading and a Tkinter interface. The server retrieves headlines and sources from NewsAPI and records client requests and activity in JSON files, while the client lets users search by keyword, category and country.

Tools: Python, TCP/IP socket programming, multithreading, Tkinter, NewsAPI, JSON, Requests library, client-server architecture
